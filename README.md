# Stundenpool

Android-App zur Berechnung des Stundenpools im Schuljahr (Niedersachsen): Vertretungsstunden und Krankheitswochen werden vom Jahres-Soll abgezogen, Ferien und Feiertage berücksichtigt.

Dieses Repository enthält nur die fertigen Versionen der App und die rechtlichen Texte. Der Quellcode ist nicht öffentlich.

## Installieren

1. Öffne die [aktuelle Version unter Releases](../../releases/latest) auf deinem Android-Handy.
2. Lade `Stundenpool.apk` herunter und tippe die Datei an.
3. Android fragt beim ersten Mal, ob dem Browser oder Dateimanager die Installation unbekannter Apps erlaubt ist. Bestätige das einmal.
4. Android oder Google Play Protect kann warnen, weil die App nicht aus dem Play Store stammt. Du kannst die Installation trotzdem fortsetzen.

## Updates

In der App unter **Einstellungen → Nach Update suchen**. Die App lädt die neue Version herunter, prüft sie und öffnet den Android-Installer. Deine Daten bleiben erhalten.
